# cyraduct.com

Marketing site for [Cyraduct](https://github.com/raheem-verisigil/cyraduct), the open consequence-boundary protocol for AI agent actions.

This is a static single-file site. The conformance section fetches live results from the deployed API (`api.cyraduct.com`, falling back to the Railway URL) rather than showing hardcoded numbers.

Deployed via GitHub Pages. See `CNAME` for the custom domain configuration.
